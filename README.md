# jerardpelaez.dev

Personal portfolio — a single self-contained HTML file styled as a paper dossier: manila folder tabs, editorial typography (Newsreader & Courier Prime, embedded as data URIs), no dependencies, no build step.

**Live:** https://jerardpelaez.dev

| File | Purpose |
|---|---|
| `index.html` | The entire site — markup, styles, fonts, and scripts in one file |
| `og-image.png` | Social share card |
| `resume.pdf` | Downloadable résumé (generated from `resume-source.html`) |

Details worth a look: real ARIA tabs with arrow-key navigation, hash deep links (`#work`), a print stylesheet that renders the whole dossier as a typeset document, and a dark mode where the desk dims but the paper stays paper.

Built by hand, with [Claude Code](https://claude.com/claude-code) as the pair.
